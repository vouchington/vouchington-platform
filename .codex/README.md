# Codex configuration

This repository tracks no Codex configuration, plugins, or marketplaces. Session journaling uses
the machine-registered `vouchington-tooling` MCP server with the `vouchington-workflow:blackboard`
skill; see [`../AGENTS.md`](../AGENTS.md). Machine sandbox, model, approval-mode, MCP server,
plugin, and startup defaults belong in the host setup described by the [agent configuration
ownership contract](https://github.com/vouchington/vouchington-machines/blob/main/docs/agent-config.md).
